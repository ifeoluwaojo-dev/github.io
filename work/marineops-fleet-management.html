01 / THE CHALLENGE

Less spreadsheet.
More clarity.

Maintenance dates, vessel details and fuel logs are easier to act on when they live together. MarineOps is an independent software portfolio project inspired by common marine engineering workflows: organise vessel information, track maintenance, and bring fuel data into focus.

This is a fictional demonstration with sample vessel and fuel data. It does not track real vessels or represent a commercial fleet management deployment.

02 / THE PRODUCT

Useful tools for
everyday operations.

Designed as a responsive single-page React application with clear navigation across connected operating tasks.

Vessel records

Add, view and edit vessel details and operational status.

Maintenance management

Record upcoming work, flag overdue tasks and mark servicing complete.

Fuel analytics

Log fuel usage, compare consumption and inspect visual trends.

Reports and exports

Review fleet summaries and export information in CSV format.

03 / HOW IT WORKS

From prototype
to live product.

MarineOps is built with React, Vite, JavaScript and CSS, deployed to Vercel from its GitHub repository. Core application logic has automated tests covering records and calculations.

The current public demo uses browser-stored sample data, so visitors can try the workflows without signing up. Supabase integration is prepared as an optional enhancement; cloud accounts and shared data have not yet been enabled.
