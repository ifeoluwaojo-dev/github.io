01 / THE IDEA

Analytical can be
expressive.

A portfolio about research doesn't have to feel like a spreadsheet. I wanted this space to show both sides of my thinking: a structured approach to evidence and a curiosity for building digital things.

The visual direction is a playful editorial language — assertive typography, colour, original vector artwork, and enough negative space to let the work speak.

02 / THE BUILD

Designed to be
simple.

The site is built with semantic HTML, CSS, and vanilla JavaScript, so it runs as a static website with no framework, database, paid hosting, or build step.

Responsive layout

Flexible arrangements for phones, tablets, and desktops.

Keyboard support

Native controls, visible focus states, and an accessible menu.

Reduced motion

Animations respect the user's motion preference.

Illustrated content

Original SVG visuals rather than copied design assets.

03 / THE EXPERIENCE

Show, don't
only tell.

The interactive mini evaluation lab is a small but purposeful feature. Visitors can compare two hypothetical responses, receive an explanation, and experience the care involved in scoring an answer.

The exercise is presented transparently as an adapted set of invented examples — not as production AI evaluation results.
